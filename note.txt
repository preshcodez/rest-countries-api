What is Routing?
Routing is the process of moving between different pages or views in an application without reloading the browser.
In traditional websites:
Click link → New page loads → Full refresh

In React (Single Page Application):
Click link → Component changes → No refresh

What is React Router DOM?
React Router DOM is a library used in React to handle navigation between different components (pages) in a Single Page Application (SPA).

It allows you to:
Create multiple pages in React
Navigate without refreshing the page
Build dynamic URLs
Handle nested routes
Handle protected routes

Why Do We Need React Router?
Without routing in React:
You only have one page (App.jsx)
Everything appears on one screen
No navigation between pages

With React Router:
You can have:
Home page
About page
Dashboard
Profile

React Hooks (Typed)
What Are React Hooks?
React Hooks are special functions introduced in React 16.8 that allow function components to use React features such as:

State management
Lifecycle methods
Side effects
References to DOM elements
Context

Before Hooks, these features were only available in class components.

Why Use Hooks?
✅ Simpler code
✅ Reusable logic
✅ Easier to read and maintain
✅ Works naturally with TypeScript

UNDERSTANDING STATE MANAGEMENT
What is State?
State is data that belongs to a component and can change over time.

Think of state as the component's memory.

Examples:
User's name
Counter value
Shopping cart items
Logged-in status
Form inputs
Theme mode (Dark/Light)

Without state, React applications would be static and unresponsive.
Real-Life Example

Imagine a banking app.

Current Balance:
₦5,000

After depositing money:
₦15,000

The balance changed.
That changing balance is state.

React uses state to keep track of changing information and update the UI automatically.

What is State Management?
State management is the process of:

Creating state
Reading state
Updating state
Sharing state between components

Simply put:
State Management = Managing changing data in an application

function App() {
  let count = 0;

  return (
    <div>
      <h1>{count}</h1>

      <button onClick={() => count++}>
        Increase
      </button>
    </div>
  );
}

When the button is clicked:
count++;

The variable changes internally but React doesn't update the screen.

Why?
Because React only re-renders when state changes.
This is why ordinary variables are not suitable for UI data.

React follows a simple pattern:

State Changes
      ↓
Component Re-renders
      ↓
UI Updates

Example:
count = 0
Click Button
count = 1
React Re-renders
UI shows 1
